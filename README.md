# Vahan Lead-Source Conversion Case Study

This case study analyzing 18,198 leads across 16 lead sources
to identify which sources convert best, build a summary SQL query, and model what
factors drive conversion to First Trip (FT).

**Top finding:** A small number of specific cohorts — including an aged-referral segment
and one high-performing acquisition batch — converted at roughly 3x the overall base
rate, independently confirmed by both a ranked aggregation and a classification model.

**Note:** Partner, agent, and campaign names have been anonymized to avoid attributing specific business performance to named entities.
Underlying figures are as provided in the original case study exercise.

See `Vahan_Case_Study_Analysis.ipynb` for full code, SQL, and charts.
