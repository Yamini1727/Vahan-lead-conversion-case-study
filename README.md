# Vahan Lead-Source Conversion Case Study

Product Analytics internship case study analyzing 18,198 leads across 16 lead sources 
to find which sources convert best, build a summary SQL query, and model what factors 
drive conversion to First Trip (FT).

**Top finding:** Referral leads aged >7 days and the Khanna 26th-Jul 2W batch convert 
at ~3x the overall base rate (0.30%) — confirmed independently by both a ranked 
aggregation and a classification model.

See `Vahan_Case_Study_Analysis.ipynb` for full code, SQL, and charts.
